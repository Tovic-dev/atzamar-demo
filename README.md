# Atzamar · demo de diseño (empresa ficticia)

Demo de una web B2B para un fabricante de pinzas robóticas **inventado**, hecha por Arnas Studio.
Atzamar no existe: la gama, las cifras, las personas y los datos son ficticios. El brazo es un modelo genérico.

- Web estática: `index.html` + `tokens.css` + `media/`.
- 3D con Three.js; movimiento con GSAP ScrollTrigger y Lenis (desde CDN).
- Modelos 3D y renders hechos en Blender para esta demo.
- Las fotos de Elgoibar son de Wikimedia Commons (CC BY-SA); los créditos y licencias están en el pie de la página. No muestran ningún taller de Atzamar.

La página lleva `noindex` y no debe indexarse.
